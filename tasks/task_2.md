# 2 - Menu principal - CLI

**Eu como:** Como usuário do Awesome-questionnaires.

**Quero:** Visualizar o menu principal.

**Para:** Selecionar opções.

**Descrição técnica:**

O objetivo deste item de trabalho é criar o menu principal da interface de linha de comando para o awesome-questionnaires. Neste momento, o foco é o fluxo de criar novo questionário.

O usuário deverá ver as seguintes opções:

---

Digite 0 para criar um novo questionário

Digite 1 para gerenciar questionarios

Digite 2 para responder questionarios


Digite 3 para sair

Por favor, digite sua opcao:

---

Comportamentos:

Caso o usuário escolha a opção 0(zero), 1 ou 2 - apresente a seguinte mensagem na tela: Opção ainda não implementada e recarregue todo o menu inicial novamente.

Caso o usuário selecione a opção 3 - deverá aparecer a seguinte mensagem na tela:


3 - Sair

========================================

Obrigado por usar Questionarios Incriveis!

========================================

E o programa deverá ser encerrado, sem erros.

Caso o usuário digite qualquer número não mostrado no menu principal, deverá ser exibida a mensagem - Opção não suportada, por favor, selecione uma opção do menu principal. Recarregue todo o menu inicial novamente.
